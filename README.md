# Hash Table, Set and Multiset (Lock-Free)

## Описание

Реализация неблокирующей (Lock-Free) хеш-таблицы, множества (Set) и мультимножества (Multiset) на языке C.

В проекте используются:
- Открытая адресация с линейным пробированием для обработки коллизий
- Хеш-функция MurmurHash3 (упрощённая версия)
- Автоматическое расширение таблицы при нагрузке > 0.75
- Lock-Free механизм на основе атомарных операций Interlocked для многопоточности

## Стек технологий

- Язык: C (C99)
- Сборка: GCC / MSVC
- Платформа: Windows (WinAPI для многопоточности)
- Тестирование: Встроенные автоматические тесты

## Тестирование

Проект содержит один комплексный тест, проверяющий работу хеш-таблицы в многопоточной среде.

### Lock-Free тест многопоточности

| Этап | Действие | Количество операций |
|------|----------|---------------------|
| 1 | 4 потока одновременно записывают данные | 4 × 1000 = 4000 записей |
| 2 | Проверка количества записанных элементов | ожидается 4000 |
| 3 | 4 потока одновременно читают данные | 4 × 1000 = 4000 чтений |
| 4 | Проверка: все ли элементы найдены | ожидается 4000 |
| 5 | Удаление половины элементов | 2000 удалений |
| 6 | Проверка размера после удаления | ожидается 2000 |

### Что проверяется

- Параллельная запись из нескольких потоков
- Параллельное чтение из нескольких потоков
- Корректность удаления элементов
- Отсутствие блокировок (Lock-Free)
- Атомарные операции CAS работают корректно

## Хеш-функция

Используется упрощённая версия MurmurHash3.

**Преимущества:**
- Отличное распределение для строковых ключей
- Высокая производительность O(n)
- Простота реализации
- Минимальное количество коллизий

**Обработка коллизий:** Открытая адресация с линейным пробированием.
