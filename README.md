# Hash Table, Set and Multiset

## Описание

Реализация хеш-таблицы, множества (Set) и мультимножества (Multiset) на языке C.

В проекте используются:
- Открытая адресация с линейным пробированием для обработки коллизий
- Хеш-функция MurmurHash3 (упрощённая версия)
- Автоматическое расширение таблицы при нагрузке > 0.75

## Стек технологий

- Язык: C (C99)
- Сборка: GCC / MSVC
- Тестирование: Встроенные автоматические тесты

## Структура проекта
├── hashmap.h # Интерфейс хеш-таблицы
├── hashmap.c # Реализация хеш-таблицы
├── set.h # Интерфейс множества
├── set.c # Реализация множества
├── multiset.h # Интерфейс мультимножества
├── multiset.c # Реализация мультимножества
├── main.c # Тесты и демонстрация
└── README.md

## Тесты

Проект содержит автоматические тесты для всех структур данных:

**Тест хеш-таблицы:**
- Вставка 7 ключей
- Проверка наличия ключей
- Проверка размера

**Тест множества (Set):**
- Объединение (Union)
- Пересечение (Intersection)
- Разность (Difference)
- Симметрическая разность (Symmetric Difference)
- Проверка подмножества (Subset)
- Проверка равенства (Equal)
- Проверка пересечения (Disjoint)

**Тест мультимножества (Multiset):**
- Добавление элементов с количеством
- Удаление части элементов
- Полное удаление элемента

**Тест производительности:**
- Вставка 1000 элементов
- Поиск 1000 элементов
- Удаление 500 элементов

## Хеш-функция

Используется упрощённая версия MurmurHash3.

**Преимущества:**
- Отличное распределение для строковых ключей
- Высокая производительность O(n)
- Простота реализации
- Минимальное количество коллизий

**Обработка коллизий:** Открытая адресация с линейным пробированием.
